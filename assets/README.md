# Recursos

Os cinco stickers sao PNGs RGBA copiados sem alteracao do trabalho `Zelda 2D Game`, fornecido como referencia:

| Sticker | Arquivo de origem no Zelda |
|---|---|
| `stickers/link.png` | `assets/extra_sprites/link_frente_3.png` |
| `stickers/princesa.png` | `assets/textures/princess.png` |
| `stickers/arvore.png` | `assets/textures/tree.png` |
| `stickers/arbusto.png` | `assets/extra_sprites/bush.png` |
| `stickers/ponte.png` | `assets/textures/bridge.png` |

Cada imagem contem pixels visiveis e pixels com alfa zero. Sao stickers estaticos, sem spritesheets ou animacao. O programa preserva a proporcao ao dimensiona-los. A composicao respeita o alfa de cada pixel.

O repositorio do trabalho anterior continua sendo a referencia de procedencia dos sprites; nao se atribui aqui nova autoria ou licenca a essas imagens.
